# NLP Reinforcement Learning

A hands-on project exploring Reinforcement Learning for Natural Language Processing using PyTorch.

## Current Implementation

- Text Generation Environment
- Policy Network using Embedding and GRU
- Policy Agent using Categorical Distribution
- Token-based Reward Function
- REINFORCE (Policy Gradient) Algorithm
- Model Evaluation using Exact Match Rate

## Experiment

- Target Text: `i like cats`
- Algorithm: REINFORCE
- Framework: PyTorch
- Training Episodes: 2,000
- Learning Rate: 0.001
- Exact Match Rate: 100%
